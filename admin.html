Como usar este painel:

1. Tipo de Página "Site Normal" é para seu portfólio. "Mentoria VIP" trava o site até o cliente ver o vídeo todo.
2. ID do Vídeo (YouTube) Vá no YouTube, copie o código final do link (depois do v=). Ex: youtube.com/watch?v=dQw4w9WgXcQ
3. Oferta Especial Muda o título principal do site. Ex: "Cupom VIP de 40% OFF".
4. Texto do Botão Personalize o texto do botão de ação. Ex: "Garantir meu Cupom".
5. Grupo WhatsApp Cole o link do seu grupo. Ele aparecerá como botão após o vídeo de Mentoria.
