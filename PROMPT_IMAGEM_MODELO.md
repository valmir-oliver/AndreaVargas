## CONFIGURAÇÕES RECOMENDADAS

**Para certificado:**
- Formato: 3:4 (retrato) ou 1:1 (quadrado)
- Resolução: Mínima 1024x1024, ideal 2048x2048 ou maior
- Estilo: Fotorealista, profissional
- Fundo: Escuro para contraste com o cabelo colorido
- Iluminação: Studio lighting
- Expressão: Confidente, elegante

---

## INSTRUÇÕES DE PÓS-PROCESSAMENTO

Após gerar a imagem:

1. **Remover fundo** (se necessário):
   - Use remove.bg ou ferramenta similar
   - Ou edite no Photoshop/Figma

2. **Ajustar cores** (se necessário):
   - Aumentar saturação do cabelo
   - Melhorar brilho
   - Ajustar contraste

3. **Redimensionar**:
   - Tamanho adequado para certificado
   - Mantenha qualidade (300 DPI se for imprimir)

4. **Salvar em formato adequado**:
   - PNG com transparência (se removeu fundo)
   - JPG de alta qualidade (se mantiver fundo)

---

## INTEGRAÇÃO NO CERTIFICADO

**Posições sugeridas:**
1. Canto superior direito (decorativo)
2. Canto superior esquerdo (decorativo)
3. Como marca d'água sutil (baixa opacidade)
4. Como elemento de fundo (muito sutil, baixa opacidade)

**Estilo:**
- Opacidade: 20-40% (se for fundo/marca d'água)
- Blend mode: Multiply ou Overlay
- Tamanho: Proporcional ao layout
- Posição: Não deve interferir com o texto

---

## EXEMPLO DE USO NO CANVA

1. Importe a imagem gerada
2. Use "Remover fundo" se necessário
3. Ajuste opacidade para 25-30%
4. Posicione no canto superior direito
5. Use blend mode "Multiply" ou "Overlay"
6. Certifique-se que não interfere com o texto
